# 四面体マトリョーシカ工房

正四面体の展開図を色紙に印刷して組み立て、入れ子（最大5層）にしてから切り開く工作のための単体HTMLアプリです。きっかけは秋山仁先生のNHK高校講座「数学と芸術」で、制作者が2007年に色紙で実験した工作を再現しました（番組内容の転載ではなく、本人の実験と体験として構成しています）。

## 型紙ジェネレーター

- 入れ子にできる寸法の展開図を、層の数（最大5層）でまとめて出力。一辺は 96／84／72／60／48mm（12mmずつの等差）
- 寸法の根拠：内側の四面体を同じ向き・同じ底面で重ねる配置で、内側の頂点から外側の斜面まで約3.3mmのすき間が残ることを幾何計算で検証（紙の厚みと包み込む余裕を含む）
- A4横・300dpiの画像書き出し（層ごと）。糊しろ・折り線・5cm確認線・おすすめの色紙の色つき
- 絵柄：内蔵模様4種（みずたま／なみなみ／さんかく／おはな）＋自分の画像を展開図に配置（端末内だけで処理し、外部送信しません）

## 切り開きシミュレーター

- 展開図の上で自由に切り取り線を描けます（面の境界をまたいでも可）
- 線が輪郭を越えたら、その辺の中点まわりの180°回転で折り返して、反対側の対応する位置から続きます。これにより、敷き詰めた平面でも切り口が継ぎ目でつながります
- 両端が輪郭にある線では、2つに切り開くアニメーション（面積比も表示）
- 敷き詰め（テッセレーション）プレビュー：展開図を平面に並べ、模様と切り口が継ぎ目でつながる様子をアニメーションで表示

入れ子の組み立て手順、切り開き方、カッター・ハサミの安全注意、コラム（展開図が平面を敷き詰められる理由、2007年の実験、入れ子の寸法計算）を収録。
